Run an agent on a sentence of your own

  
Give a text and the sentence in it you want audited. An agent, a Claude
  model called with your own API key, audits the sentence by the card: it quotes it, marks
  the word it turns on, commits to what would change its mind, reads the text, spells out
  the readings and proposes a verdict. It stops where a person is needed. Then it is your
  turn, in the playground.

  
    
    
  • Your key stays in this page. It is held in memory only, never stored, and
      sent only to api.anthropic.com. Reload the page and it is gone.
    • 
    
  • It costs money. Each turn is billed to your key. A run is typically 20 to 40
      turns. Set a turn limit below, and stop the run at any time.
    • 
    
  • The rules are the server's. The agent writes through the same checks as the
      MCP server, ported to JavaScript: it may not write a holder, grant, settle or decide;
      words it puts in quotation marks, in an entry that cites what it fetched, must be in that text (an entry that cites nothing is not checked); a look must not cite what it read before its
      commit. What is refused is shown, with the rule.
    • 
    
  • Your text goes to the model. Only what the agent fetches with read
      is sent, a slice at a time, but do not paste what you would not send to an API.
    •

Opus and Sonnet are called with server-side fallbacks on: if the model is
  overloaded, the API may answer with another model, and the run says which.


  
2 The text

  
One or more documents. The agent reads them by name and line number, as
  it reads files on the server. The first holds the sentence. Plain text works best; LaTeX
  is read with and without its markup.
